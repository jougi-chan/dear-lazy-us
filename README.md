# Dear Lazy Us

Web ページや PDF を読みながら、その場で AI に翻訳・解説してもらえる Windows アプリです（無料）。作り手：定規

- くわしい説明・使い方・プライバシーポリシー・利用規約：[Google サイト「定規」](https://sites.google.com/view/jougi/dear-lazy-us)
- ダウンロード：[Releases](https://github.com/jougi-chan/dear-lazy-us/releases) から `DearLazyUs-Setup-<版>.exe` を取得してください（SHA-256 は各リリースに載せています）。同じファイルを [BOOTH](https://jougi.booth.pm/) でも配っています（BOOTH は zip に入れています）。
- ご質問・不具合の報告：[Issues](https://github.com/jougi-chan/dear-lazy-us/issues)（返答は保証できません。API キーや個人情報、資料の中身は書かないでください）

このリポジトリは配布のためのものです。ソースコードは置いていません。
